# Ezequiel Isaac — Portfólio V6

## Instalação
Abrir `index.html` no navegador ou usar Live Server no VS Code. Para publicar, enviar o conteúdo desta pasta para um alojamento estático.

## Alterações
- Nova secção Ferramentas, com ícones locais de inspiração 3D nas cores associadas a Photoshop, Illustrator, Figma e Antigravity.
- Organização editorial mais contida, botões arredondados e melhor espaçamento.
- Projectos, filtros, carrosséis, modo escuro e assistente comercial preservados da V5.
- Textos principais revistos.

## Personalizar
- `index.html`: textos, menus, fotografia, secções.
- `v6.css`: ajustes da V6.
- `projects.js`: nomes, categorias, descrições e imagens de cada projecto.
- `assets/`: substituir os recortes do PDF por imagens originais de alta resolução.
- `assistant-config.js`: serviços, preços, prazos e contactos.
- `assistant.js`: comportamento do assistente.

## Nota sobre os ícones
Os ícones das ferramentas são representações SVG estilizadas, com profundidade e cores características; não são os ficheiros oficiais tridimensionais das marcas. Para fidelidade absoluta, substitui-os por recursos oficiais licenciados.

## Assistente
Continua a usar respostas por regras e palavras-chave. Não é um modelo generativo nem pode fechar contratos sem confirmação humana. Não colocar chaves de API no JavaScript do navegador.
