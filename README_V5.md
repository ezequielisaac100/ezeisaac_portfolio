# Ezeisaac Portfolio V5
Website estático completo, pronto a abrir no VS Code ou Antigravity.

1. Abre `index.html` para testar.
2. Substitui as imagens em `assets/` pelas tuas originais e ajusta `projects.js`.
3. Personaliza serviços, preços e prazos em `assistant-config.js`.
4. Verifica os contactos e testa a abertura do WhatsApp.
5. Para IA generativa, será necessária integração de backend.

As imagens incluídas são recortes do PDF de portfólio e devem ser substituídas por imagens originais de alta resolução.
