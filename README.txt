EZEQUIEL ISAAC — WEBSITE PORTFÓLIO V2
====================================

COMO ABRIR
1. Extrair o ZIP para uma pasta.
2. Abrir index.html num navegador moderno.
3. Para publicar, enviar todos os ficheiros e a pasta assets para o alojamento (Netlify, AngoHost, etc.).

O QUE FOI ACTUALIZADO
- Interface editorial mais natural, clara e profissional.
- Modo claro e escuro no cabeçalho; preferência guardada no navegador.
- Ícones SVG, sem emojis.
- Trabalhos separados por marcas e por campanhas.
- Carrossel directamente nos cartões: primeira vista com até quatro artes, seguida de peças individuais.
- Deslizar com o dedo no telemóvel, trackpad ou setas nos cartões.
- Visita automática, interrompida ao clicar no ecrã ou no botão.
- Menu mobile e filtros por área.

COMO ALTERAR OU ADICIONAR PROJECTOS
- Colocar as imagens na pasta assets.
- Abrir projects.js e editar a lista window.PORTFOLIO_PROJECTS.
- Cada projecto tem: title (nome), category (social, branding, campaign, corporate), images (lista de ficheiros), desc e kind.
- A capa é criada automaticamente com as primeiras quatro imagens. Depois cada imagem aparece individualmente no carrossel.
- O ficheiro projects.json contém a mesma lista como referência; o site lê projects.js para funcionar mesmo sem servidor.

NOTA SOBRE AS IMAGENS
As imagens foram recortadas a partir das páginas de composição do PDF fornecido. A resolução e o enquadramento estão limitados por esse documento. Algumas marcas não estão identificadas de forma inequívoca no PDF; nesses casos, foram usadas descrições neutras. Substituir as imagens recortadas pelos ficheiros originais e confirmar nomes de marca antes de publicar.
